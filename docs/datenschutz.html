Datenschutz

Kurz gesagt

  • Kein Tracking, keine Analyse-Tools, keine Werbung, keine Cookies zu Werbe- oder Analysezwecken.
  • Ihre Daten (übernommene Ausschreibungen, Leistungsverzeichnisse, Preise, Firmenprofil, Einstellungen, ggf. eingegebene Zugangsdaten) bleiben in Ihrem Browser (IndexedDB) auf Ihrem Gerät. Sie werden nicht an uns oder Dritte übertragen.
  • Entwürfe im Bereich „Für Auftraggeber“ (Ausschreibung veröffentlichen) speichert Lospilot ebenfalls nur in Ihrem Browser (localStorage). Lospilot veröffentlicht oder versendet sie nicht; das Export-Paket laden Sie selbst herunter.
  • Importierte Dateien (PDF, Word, Excel, GAEB) werden direkt in Ihrem Browser ausgewertet und nicht hochgeladen.
  • „Fehler melden“ und „Vorschlag senden“ öffnen GitHub oder Ihr E-Mail-Programm mit einem vorausgefüllten Text. Erst wenn Sie dort selbst absenden, wird die Nachricht übertragen; dann gilt die Datenschutzerklärung von GitHub bzw. Ihres E-Mail-Anbieters.
  • Mit „Daten sichern“ können Sie eine Sicherungsdatei herunterladen. Löschen Sie die Browserdaten für diese Seite, sind die Daten im Browser weg.
